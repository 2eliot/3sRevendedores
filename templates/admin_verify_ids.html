Cómo rellenar los campos (ejemplo)

En la URL, el cuerpo y las cabeceras puedes usar {player_id}, {player_id2} (Zone ID / Server ID) y {servidor}. En Ruta del nombre indica dónde viene el nombre del jugador en la respuesta, separando con puntos.

URL:            https://api.tuproveedor.com/v1/check?uid={player_id}&zone={player_id2}
Cabeceras:      {"X-API-Key": "tu-clave-secreta"}
Respuesta:      {"status": "ok", "data": {"nickname": "ProPlayer99"}}
Ruta nombre:    data.nickname
Ruta error:     message   (opcional: mensaje que devuelve el proveedor si falla)
